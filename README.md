## What the free version covers, and who shouldn't pay

Process Lasso's main feature is ProBalance, which watches running processes and temporarily lowers the priority of anything hogging the CPU so the program you're actually using keeps responding. That mechanism is in the free build. The paid Pro edition adds extras such as per-application power plans, limits on how many instances of a process can run, and controls for keeping processes awake.

So the honest boundary is this: if what you want is the background-process-throttling behaviour, the free version gives it to you. Pay for Pro when you need those extra controls on specific applications, or when you want the vendor's support and a licence that's unambiguously valid for how you're using it.

There are also people who shouldn't buy at all. If you're on Windows 11 with a recent CPU, the system scheduler is decent, and the gains from priority juggling are much smaller than on older hardware. Process Lasso doesn't add RAM, doesn't fix a failing drive, and doesn't make a ten-year-old laptop fast. It manages contention. If your machine is slow because a specific program is badly written or because you're running out of memory, you'll get more from addressing that.
